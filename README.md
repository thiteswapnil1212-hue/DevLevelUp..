# DevLevelUp — Backend

Express backend for **DevLevelUp** (evidence-first developer career audit tool) — unified server, Railway-oriented.

**Related:** [devlvlup](https://github.com/thiteswapnil1212-hue/devlvlup) (live demo at https://devlvlup.vercel.app/)

## Tech stack

Node.js 18 · Express · CORS · dotenv

## Getting started

```bash
npm install
npm run dev      # with nodemon
npm start        # production
```

Copy `.env.example` to `.env` and fill in the required values. Never commit real secrets.
